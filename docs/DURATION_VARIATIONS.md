# Phase 9 Step 9：ギター音価だけの比較

Step 8-Cをユーザーが最良と評価した記録を持ち、Aをそのまま維持する。
既存生成器と既定値を変更しない任意の実験スクリプト。

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/create_duration_variation_auditions.py \
  examples/requests/chorus_duration_variations.json output/phase9_step9_duration_variations
```

実測：60発音グループ・90ノート、単音30／power5二音30。
グループ音価は.25拍×56／.5拍×4、音符単位は.25拍×82／.5拍×8。
次の発音までの間隔59件は.5拍×52／.75拍×3／.25拍×2／1.25拍×2。

- A：元のStep 8-Cのバンド・ギター・ベースをバイト一致でコピー。
- B：弱いvelocity76の既存.25拍ゲートだけ半分の.125拍へ。強い96/100/108と
  既存4件の.5拍は保持。28件短縮、残る32件は不変で、全て極端な短音にはしない。
- C：Bの短音ベースに、各小節step8（小節内2拍＝第3拍）の
  velocity100アクセント8件を.5拍へ。実測IOIに.5拍以上の余裕がある位置だけ。
  既存の第2/6小節step12、第4/8小節末尾step13の.5拍も保持し、計12長音。

.125は基準の弱い.25拍の半分、.5は既存長音で実際に使われている長さ。
闇雲な固定値ではなく、基準の音価・強弱・IOIの対比から選んだ比較設定。
音価制御をPalm MuteやStaccatoの確定奏法と呼ばず、キーを推定追加しない。

各グループ内のNote Offだけを移動し、全構成音を同じ長さにする。
発音位置・pitch・velocity・単音／和音配置・内部音程・チャンネル・Program・marker等は固定。
長さは次発音、小節境界、曲末を越えないよう必要時に短縮し、同tickではNote Off先行。
今回はサンプルでの安全短縮は不要。合成テストで重複・小節末処理を確認。

ベース・ドラムは全候補で原本バイトコピー。ベースをギターの新しい音価へ再追従
生成すると固定条件に反するため、元のA2のNote Offも維持する。
B/CではギターとベースのOn/pitch/velocity関係は同じだが、一部Note Offは異なる。

グループ単位の60件と音符単位90件を分け、音価平均と分布、59区間のGate/IOI、
次発音までの無音、曲末の尾、長音位置、反復一致率を記録。MIDIゲートが閉じた時間と
音源の実際の減衰・無音は区別する。候補の採用は試聴後、数値だけでは決めない。
