# Phase 9 Step 2 — 採用8小節モチーフの保持

## 確認した原因

Step 7-Bは `scripts/create_groove_backing_auditions.py` →
`generate_backing_phrase()` に同じ `RhythmBlueprint(kick=(0,), snare=(8,), accent=(0,8))`
を渡し、phrase4 / mixed / 0.75 / 基本1ステップ / contrastで作る。
実際の構造は A / Aの小変化 / A / 締め を2回繰り返した8小節。
1〜2小節と5〜6小節は一致し、4・8小節の長い休符と短長音価が特徴。

一方、Phase 9 Step 1 の `scripts/run_reference_band_demo.py:build()` は各4小節
ブロックで別のドラムの先頭小節を生成し、`extract_rhythm_blueprint()` を再実行していた。
`generate_backing_steps()` は全キックを残し、`_phrase_positions()` はキックを
移動・削除しないため、新しいキック10/12などが採用版の休符を埋めた。
密なブループリントでは `_refine_phrase()` の安全な長音候補も変わった。
また、キック由来の強アクセントと `_ratio_chord_indices()` の配置も入力に連動する。
乱数による毎小節生成やタイミング精度の問題ではない。

4小節ごとの再開始だけでは、もともと4小節周期のStep 7-Bが崩れる理由にはならない。
確認された主因はブループリントの差し替えと、セクション/部分ブロックでの切り出し。
既存計画のセクション境界そのものを変更する必要はない。

## 最小修正と互換性

タスク用ハーネスの設定に任意の `guitar_motif` を追加した。
`rule_backing.py`、ドラム生成器、ベース生成器とそれらの既定値は変更していない。
このキーを省略した旧Phase 9設定は、元の4 MIDIとバイト一致する。

```json
"guitar_motif": {
  "phrase_bars": 8,
  "blueprint": {"kick_steps": [0], "snare_steps": [8], "accent_steps": [0, 8]}
}
```

`section_motif()` が既存 `generate_backing_phrase()` をセクションにつき1回呼ぶ。
`motif_slice()` はセクション内の小節番号を8で循環し、ドラムの4小節ブロックが
切り替わっても0〜3→4〜7→0〜3と維持する。設定のセクション長は変えない。
2/4/4/4.5/12小節の現構成では、短いセクションは先頭を取り、半小節は既存の
半開区間クロップ・境界Note Offで処理する。足りない小節を埋めたり増やしたりしない。

セクションのリズム構造は意図的に同じ採用モチーフを共有する。
イントロの既存固定ベロシティとドラムの素材・切替は維持する。
全キック追従のために音を加えず、主要なセクション内拍頭が一致することを確認する。
ベースは従来の−24半音追従で、同じオンセット・音価・休符を持つ。

## 比較生成

```sh
.venv/bin/python scripts/run_groove_consistency_demo.py \
  examples/requests/not_my_time_groove_consistency.json \
  output/phase9_not_my_time_first_chorus \
  output/phase9_step2_groove_consistency
```

出力先は新規にする。基準8小節、修正前後の統合MIDI、修正後の各パート、
同じサビ先頭8小節の前後比較、定量JSONと比較表を保存する。
基準ギターはSHA-256と再生成イベント一致を確認し、原ファイルのバイトをコピーする。
比較用8小節には冒頭無音を付けず、楽曲全体では従来の0.45秒を保持する。
`after_song/` は作業ファイルを含む再現記録で、試聴はトップレベルのMIDIを使う。

## 指標の定義と限界

- オンセット類似性：16分グリッド集合のJaccard＝共通位置数／和集合位置数。
  和音はルート発音1回として数える。1〜2対3〜4、5〜6、7〜8も同じ定義。
- 主要休符：基準小節内で連続2ステップ以上の無音。基準の無音セルのうち
  生成側でも無音の割合を測る。通常の8分刻みの1セル空きは区別する。
- 音価：0.25/0.5拍の分布、共通オンセットでの基準音価一致。
- アクセント：実ベロシティ一覧と、その小節最大値の90%以上の位置。
  イントロの固定強度設定により閾値分類が変わることがある。
- キック同期：既存0.04拍の許容差で比較し、セクション内拍頭とその他を分ける。
  ドラムの微小ずれは保持する。全キック一致率はグルーヴ品質そのものではない。
- 短い区間：存在しない完全小節の比較はnull。パディングで完全一致を捏造しない。

Step 7-Bの1〜2対3〜4/7〜8は13/17≒0.765、対5〜6は1.0。
終止変化があるので、全ペアの類似性を最大化することを改善目標にしない。
サビ以前のセクション名・境界は引き続き推定、サビ15.3〜27.3は既存のユーザー指定。
音楽的改善は試聴で評価し、機械検証だけで良否を断定しない。
